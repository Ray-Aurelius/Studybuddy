tip_1_title = 分散学习
tip_1_body = 一周内几次短时学习胜过一次长时间突击。分散练习是学习研究中最可靠的发现之一。
tip_2_title = 自我测验
tip_2_body = 读完后合上书，写下你记得的内容。主动回忆比重读更能巩固记忆。
tip_3_title = 交错练习
tip_3_body = 轮换不同主题或题型，而不是一次只练一种。感觉更难，而这正是它有效的原因。
tip_4_title = 讲给别人听
tip_4_body = 用简单的语言解释这个概念，就像讲给一个好奇的十二岁孩子听。解释中的漏洞就是理解中的漏洞。
tip_5_title = 定好时间和地点
tip_5_body = 「我晚上 7 点在餐桌前学习」比「今晚学一下」更容易真正做到。
tip_6_title = 睡一觉
tip_6_body = 睡眠会巩固白天所学。熬夜突击往往得不偿失。
tip_7_title = 略高于舒适区
tip_7_body = 选择稍微有点难的练习。如果觉得轻松，你是在复习，而不是在学习。
tip_8_title = 一句话反思
tip_8_body = 以「我学到的一件事」结束一次学习，是一次小小的回忆练习，也能让你看到自己的进步。
tip_9_title = 守护专注
tip_9_body = 专注时段把手机放到另一个房间。即使扣在桌上，它也会分散注意力。
tip_10_title = 建立联系
tip_10_body = 问自己：「这和我已知的什么有关？」相互关联的知识更容易回想起来。
tip_11_title = 原谅中断
tip_11_body = 错过一天不会毁掉一个习惯。重要的是第二天继续。
tip_12_title = 文字 + 图像
tip_12_body = 把你正在学的东西画成一张简图。图像和文字结合，给记忆两条通道。
tip_13_title = 多问为什么
tip_13_body = 阅读时不断问自己：「为什么是这样？」自我解释能把事实变成理解。
tip_14_title = 以计划收尾
tip_14_body = 每次学习结束时，记下下次从哪里开始。开始是最难的部分，给未来的自己行个方便。
