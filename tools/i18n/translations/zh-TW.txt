tip_3_title = 交錯練習
tip_3_body = 輪換不同主題或題型，而不是一次只練一種。感覺更難，而這正是它有效的原因。
tip_4_title = 講給別人聽
tip_4_body = 用簡單的語言解釋這個概念，就像講給一個好奇的十二歲孩子聽。解釋中的漏洞就是理解中的漏洞。
tip_5_title = 定好時間和地點
tip_5_body = 「我晚上 7 點在餐桌前學習」比「今晚學一下」更容易真正做到。

tip_7_title = 略高於舒適區

tip_9_title = 守護專注

tip_11_title = 原諒中斷
tip_11_body = 錯過一天不會毀掉一個習慣。重要的是第二天繼續。
tip_12_title = 文字 + 影象
tip_12_body = 把你正在學的東西畫成一張簡圖。影象和文字結合，給記憶兩條通道。
tip_13_title = 多問為什麼
